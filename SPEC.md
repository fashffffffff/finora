# Finora — техническое задание (этап «Прототип»)

Дата фиксации: 16.09.2026. Владелец: Рахматуллин Динар.
Этот документ — короткая запись всех решений по проекту. Написан простым языком.

## 1. Что такое Finora

Локальное приложение для macOS, в котором видны все деньги пользователя: операции,
статистика доходов и расходов, цели накоплений. Главный принцип — **приватность**:
данные лежат на компьютере пользователя и никуда не отправляются.

Сейчас строим **прототип**: всё выглядит и работает как настоящее приложение,
но банковские данные и ИИ — заготовка на будущее (подключим позже без переделки интерфейса).

## 3. Экраны приложения

1. **Dashboard (главная)** — баланс, доходы, расходы, изменение за период, последние операции, мини-графики. Период выбирается любой.
2. **Operations (операции)** — полный список: поиск, фильтры, сортировка, выбор периода.
3. **Карточка операции** — подробности, смена категории, комментарий.
4. **Review (разобрать)** — очередь непонятных операций («Перевод 25 000 ₽ — на что потрачены?»). Пользователь выбирает категорию или отмечает «перевод между моими счетами». В меню показывается бейдж с количеством.
5. **Analytics (аналитика)** — расходы по категориям, динамика по месяцам, сравнение периодов, крупные траты, заметки о привычках. ИИ здесь пока нет.
6. **Цели** — накопить на машину/квартиру и т.п.: название, сумма цели, прогресс, пополнение. Советы ИИ по экономии — в планах (см. TODO).
7. **Банк** — экран подключения Т-Банка. Кнопка «Подключить» запускает показную последовательность (Подключение → Авторизация → Синхронизация → Готово). Настоящего API пока нет, но код разделён так, что «настоящий» банк потом встанет на место «показного» без переделок.
8. **Синхронизация** — когда синхронизировались, сколько операций загрузили, журнал синхронизаций, кнопка «Синхронизировать», показ ошибки с повтором.
9. **Настройки** — профиль, внешний вид (темы/цвета), данные и экспорт, категории, приватность, о приложении, демо-режим.

**Onboarding** — 4 приветственных шага при первом запуске, можно пропустить.

## 4. Внешний вид

- Тёмная и светлая темы, переключатель. По умолчанию — тёмная.
- **4 готовых цветовых пресета** + ручная настройка цветов. Настройки внешнего вида сохраняются в собственные пресеты, есть история изменений (можно откатиться на любой шаг) и возврат к заводским пресетам.
- Фон — приятный, однотонный с едва заметной текстурой. **Без градиентов** (максимум — аккуратные отдельные случаи).
- Скругления средние (16px по умолчанию), настраиваются.
- Карточки плоские с тонкой границей, без «стеклянных» эффектов.
- Интерфейс просторный, «дорогой», в духе хороших банковских приложений.
- Шрифты: Onest (основной), Unbounded (крупные заголовки, логотип), JetBrains Mono (суммы — цифры ровным столбиком).
- Иконки — тонкие линейные + цветные плитки категорий, как в банках.
- Анимации в приложении — строгие, короткие и приятные, без экспериментов.
- На сайте наоборот — яркие, запоминающиеся анимации (но со вкусом).

## 5. Категории (базовый набор)

Продукты, Кафе и рестораны, Транспорт, Жильё и коммуналка, Здоровье, Развлечения,
Подписки, Одежда, Техника, Образование, Путешествия, Подарки, Переводы, Прочее.
Категории в отчётах банка обычно уже подписаны — Finora опирается на это, а непонятное отправляет в «Разобрать».

## 6. Показательные данные

12 месяцев правдоподобных операций: зарплата, подработка, продукты, кафе, подписки,
переводы друзьям, возвраты, комиссии, кэшбэк, переводы между своими счетами,
крупные покупки и «неизвестные» операции для очереди Review. Данные полностью синтетические.

## 7. Что кнопки делают по-настоящему

Подключить банк → показывает процесс подключения. Синхронизировать → грузит новые операции.
Фильтр → меняет список. Смена категории → сохраняется. Review → разбирает очередь.
Экспорт → сохраняет файл CSV (открывается в Numbers/Excel) и JSON (резервная копия) на компьютер.
Демо-режим → сброс данных к исходным + повторный показ приветствия; включается в настройках и легко убирается из финальной версии.

## 8. Устройство кода (важно для будущего)

Путь данных: Банк (сейчас MockBankProvider, позже TBankProvider) → Нормализатор →
Хранилище операций → Классификатор (сейчас правила; позже локальный ИИ; облачный — выключен по умолчанию) → Аналитика → Интерфейс.
Слои разделены: интерфейс не знает, откуда пришли данные, поэтому замену «показного» банка на настоящий и подключение ИИ сделаем без переделки экранов.

## 9. Сайт (для конкурса)

Страницы: **Главная** (что это, проблема, решение, как работает, приватность, снимки интерфейса, команда, контакты), **Приватность** (подробнее, почему данные не уходят), **Технологии** (архитектура, стек, планы). Навигация, анимации при прокрутке, живой мини-дашборд в заглавии, адаптив.
