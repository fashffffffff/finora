# Finora

**Локальный анализ личных финансов для macOS.** Все банковские операции — в одном
интерфейсе, с понятной статистикой и целями. Данные не покидают ваш компьютер.

## Быстрый старт

Нужны Node 20+ и (для нативной сборки) Rust/Cargo.

```bash
# Приложение в браузере (разработка)
cd app
npm install
npm run dev            # http://localhost:1420

# Приложение как нативное окно macOS
npm run app:dev        # tauri dev
npm run app:build      # .app и .dmg в app/src-tauri/target

# Сайт — обычные файлы, достаточно открыть website/index.html
# или поднять любой статический сервер из корня репозитория:
python3 -m http.server 8080   # сайт: /website/index.html, прототип: /app/dist/
```

Первый запуск приложения показывает онбординг и пустое состояние.
Нажмите **«Подключить банк» → «Подключить»** — демонстрационный источник
загрузит 12 месяцев реалистичных операций (полностью синтетических).

## Что умеет прототип

- **Дашборд** — баланс, доходы, расходы, свободные деньги, динамика, категории, наблюдения. Любой период.
- **Операции** — поиск, фильтры по типу/категории/периоду, сортировка, группировка по дням, экспорт CSV.
- **Карточка операции** — полные детали, смена категории, комментарий.
- **Разобрать** — очередь неопределённых операций, выбор категории или «перевод между счетами».
- **Аналитика** — структура расходов, 12 месяцев, крупные траты, сравнение периодов, наблюдения на правилах.
- **Цели** — накопления с прогрессом, пополнением и темпом «в месяц».
- **Банк** — показательный сценарий подключения Т-Банка (mock-провайдер за реальным контрактом).
- **Синхронизация** — статусы, журнал, обработка ошибок, кнопка «Тест ошибки».
- **Настройки** — профиль, 4 темы + полная кастомизация (акцент, скругления, плотность, свои пресеты, история изменений), категории, экспорт, приватность, демо-режим.

Все кнопки в прототипе рабочие: подключение, синхронизация, фильтры, смена
категорий, экспорт файлов и сброс демо-данных действительно выполняются.

## Приватность

Прототип не имеет серверов и аккаунтов: данные живут в localStorage браузера
(в финальной версии — в локальной БД Rust-ядра). Облачный AI исключён
архитектурно. Подробности — на [сайте](website/index.html) и в `ARCHITECTURE.md`.
