# Finora — доработка концепции и анализ рынка

**Дата:** 19.09.2026. Статус: рабочий документ для стратегии и презентации.
Основание: фидбек с созвона («идею надо доработать»), собственный анализ рынка.

---

## 1. Переформулировка идеи

**Было:** «Приложение для учёта личных финансов с локальной нейросетью».
Слабость формулировки: учёт трат — коммодити (в каждом банке и в десятке
приложений), локальность звучит как техническая деталь, а не ценность.

**Стало:** «**Личный финансовый агент, который живёт у тебя, а не в облаке.**
Он сам разбирает твои операции, замечает странные траты и спрашивает о них,
копит контекст твоей жизни и объясняет деньги человеческим языком. Работает
локально (данные не покидают устройство) или через облако — выбирай».

Ключевой сдвиг: **продукт — не аналитика, а агентное поведение**. Аналитика —
гигиена, агент — дифференциатор. Два столпа отличия от всего рынка РФ:
1. **Кросс-банковость** — все счета в одном месте (банковские ассистенты
   видят только свой банк).
2. **Приватность на уровне архитектуры** — нет серверов вообще; банковские
   AI-ассистенты (Тая у Т-Банка, GigaChat у Сбера) — облачные и
   экосистемные.

## 2. Что нашёл по рынку (проверяемые факты)

### 2.1. Конкуренты и цены (РФ)

| Сервис | Цена | Слабость, которую используем |
|---|---|---|
| Дзен-мани | 1 490 ₽/год (~129 ₽/мес), «навсегда» 2 990 ₽ | нет AI-агента, облако |
| CoinKeeper Platinum | 999 ₽/год (App Store), 1 790 ₽/год (web) | нет AI, облако |
| Money Manager / Monefy / Money Lover | дешевле или бесплатно | ручной ввод, нет AI |
| Т-Банк «Тая» / «Вселенная AI-ассистентов» | бесплатно для клиентов | только данные Т-Банка, облако, нет разбора трат по задачам |
| Сбер / GigaChat | внутри экосистемы | только Сбер, облако |

Критическая деталь: **оплата зарубежных сторов из России затруднена**
(обходные пути с комиссией 450–550 ₽) — у конкурентов болит монетизация,
у нас с первого дня будут прямые рублёвые платежи.

### 2.2. AI-ассистенты банков — честный расклад

Т-Банк запустил «Вселенную AI-ассистентов» весной 2024 и ассистента «Тая»
(покупки/финансы, доступен даже не-клиентам). Сбер внедрил ИИ в 300+
процессов. **Значит тезис «в России никто ничего не делает» — неверен и в
презентации его не использовать.** Корректный тезис: «у банков AI —
облачный, внутри одного банка, и не агент по тратам; наш агент —
кросс-банковый, локальный и проактивный».

### 2.3. Стоимость облачных моделей (для облачной версии)

- GigaChat Lite: **0,065 ₽ / 1000 токенов** (после снижения цен Сбером на
  67,5% с октября 2025; в феврале 2026 пакетные тарифы снижены ещё в 3 раза)
  → 65–200 ₽ за 1 млн токенов.
- GigaChat Pro: ~0,50 ₽ / 1000 токенов (для сложных запросов).
- DeepSeek: ~$0,3–1,1 / 1 млн токенов — дёшево, но вопрос юрисдикции;
  для РФ-продукта приоритет — российские модели (GigaChat, YandexGPT) или
  open-source (Qwen) в Яндекс.Облаке / VK Cloud.
- **Дата-центры не нужны.** Хостинг открытой модели в облаке — аренда,
  не капитальное строительство.

**Юнит-экономика облачного пользователя:** тяжёлый пользователь —
30 сообщений/день × ~1 200 токенов ≈ 1,1 млн токенов/мес:
- GigaChat Lite: ~70–220 ₽/мес переменных затрат;
- подписка 249 ₽/мес → маржа положительная даже на самом активном;
- локальная версия: переменные затраты 0 ₽ (маржа ~100%);
- тариф «по использованию» (кредиты) убирает риск кэптивных пользователей.

### 2.4. Платформа

macOS — порядка 5–8% десктопов РФ (оценка StatCounter, уточнить перед
презентацией). Смартфоны — преимущественно Android. Вывод: Mac — витрина
и старт, но для выручки нужны **веб-версия и Android** (облачная версия
это позволяет: тяжёлую модель гоняет сервер).

### 2.5. Каналы продвижения — реальность TikTok

- **TikTok: загрузка видео из РФ заблокирована с 2022.** Обход через VPN —
  с риском бана аккаунта. Значит таргетировать российскую аудиторию через
  TikTok напрямую нельзя.
- Что работает в РФ: **VK Клипы** (главный заменитель), **YouTube Shorts**
  (замедлен, но смотрят), **Telegram** (каналы + посевы у фин-блогеров).
- TikTok остаётся в стратегии для **глобальной версии** продукта (аккаунт
  с зарубежным представительством), не для РФ.
- Вирусный формат для шортов: «спросил агента — он нашёл утечку 8 000 ₽/мес»
  (скрин демо-диалога + ответ). Короткие, конкретные, с цифрами.
- Юридический нюанс: реклама финансовых услуг в РФ требует маркировки и
  раскрытия лицензий; Finora не совершает операций с деньгами и формально
  не финуслуга, но копирайт промо проверить у юриста + дисклеймер
  «не является индивидуальной инвестиционной рекомендацией».

### 2.6. Оценка объёма (черновая, для проверки)

- TAM: все пользователи онлайн-банкинга в РФ — ~90–100 млн человек.
- SAM: те, кто готов пользоваться сторонним фин-сервисом и платить за
  подписку — по масштабам платящих подписчиков финтрекеров РФ ~300–700 тыс.
  человек × ~1 500 ₽/год ≈ **0,5–1 млрд ₽/год**.
- SOM (год 1, только B2C): 3–10 тыс. платящих ≈ **3–8 млн ₽**.
- Один B2B-пилот с банком (лицензия движка) — потенциально сопоставим с
  годовой розницей. Точные цифры — отдельная задача исследования.

## 3. Стратегия входа: три этажа

### Этаж 1 — Local (сейчас, 0–6 мес)
То, что уже работает: Mac-приложение, локальная дообученная модель,
приватность архитектурно. Добавить: импорт выписок CSV/PDF (универсально
для всех банков РФ — легально и без API), ручное добавление налички.
Монетизация: разовая покупка (1 490–2 990 ₽, по рынку) — без рисков
себестоимости: переменные затраты нулевые.

### Этаж 2 — Cloud (6–18 мес)
Веб-версия и Android + выбор облачной модели (GigaChat/YandexGPT/Qwen в
RU-облаке). Подписка 199–299 ₽/мес. Снимает ограничения платформы и
даёт апгрейд качества модели. Данные — в RU-юрисдикции, с явной зоной:
«локальная зона — максимум приватности, облачная — максимум удобства,
выбор за пользователем».

### Этаж 3 — B2B2C (параллельно, питч уже сейчас)
Белый лейбл для банков: «AI-советник в приложении банка, который не
отправляет данные клиентов в облако». Банку решает регуляторные и
репутационные риски, не нужно строить ML-команду. Нам — лицензионный
контракт (единицы млн ₽/год), который перекрывает год розницы.
Работающий прототип + дообученная модель = можно питчить уже сейчас.

## 4. Откуда брать операции (проблема «у банков нет API»)

1. **Импорт выписки CSV/PDF** — все банки РФ отдают выписку; универсально,
   легально, готово к MVP. Приоритет №1.
2. **Парсинг пуш/SMS** — этап 2, полуавтоматизация без легальных рисков.
3. **Партнёрские интеграции** — переговоры с банками (по сути, продажа
   Этажа 3): если банк — партнёр, данные текут напрямую.
4. **Наличка** — ручное добавление в два касания (+ скан чека позже).
   Гигиена, не дифференциатор.

## 5. Риски и ответы (готовый слайд)

| Риск | Ответ |
|---|---|
| Банки скопируют | Мы и есть поставщик для банков (Этаж 3); кросс-банковость банк себе не сделает |
| У банков уже есть AI (Тая) | Облачный, одноканальный, не агент по тратам; наш — локальный, кросс-банковый, проактивный |
| Приватность — ниша | Этаж 2 (облако) для мейнстрима; локальность — дифференциатор и B2B-аргумент |
| Mac-аудитория мала | Этаж 2: веб + Android на облачной модели |
| Оплата подписок из РФ затруднена | Прямые рублёвые платежи с первого дня — конкурентам больно, нам плюс |
| API-расходы съедят подписку | GigaChat Lite: ~70–220 ₽/мес на самого активного; подписка 249 ₽ + кредиты |
| Модель наврёт | Цифры считает приложение (модель только формулирует); честные пометки fallback |

## 6. Питч (30 секунд)

«Финансовые приложения показывают, что было. Банковские AI-ассистенты —
облачные и видят только свой банк. Finora — личный финансовый агент:
он сам разбирает операции, замечает странные траты и спрашивает о них,
работая локально на устройстве пользователя — данные не покидают
компьютер архитектурно, а не обещанием. Прототип уже работает: нативное
Mac-приложение с дообученной нами моделью. Три этажа монетизации:
разовая покупка локальной версии, подписка на облачную для массовой
аудитории, и лицензия движка банкам — где один контракт равен году
розничной выручки».
