Стек

Приложение

  • Tauri 2 + Rust (Cargo) — нативная оболочка macOS, лёгкая и быстрая
  • TypeScript без фреймворков — Vite, свои компоненты, свой роутер
  • Свои SVG-графики — донаты, столбцы, спарклайны без библиотек
  • Шрифты — Onest, Unbounded, JetBrains Mono (кириллица)

Дальше

  • Rust-ядро — получение выписок и локальная БД (SQLite)
  • Ollama — локальные LLM на Apple Silicon для классификации и советов
  • Другие банки — новый провайдер = один класс + конфиг
